# 일검풍운결 세이브 에디터 v1.0

스팀판 `v1.24.32`, 무료 확장팩 및 유료 확장 콘텐츠 3종, 한국어 패치 데이터를 기준으로 제작된 세이브 파일 무손실 편집기입니다. 일반 저장 슬롯(`0.sav`, `1.sav` 등)과 전역 설정 파일(`JHSaveConfig.sav`)을 원본 데이터 훼손 없이 100% 한국어 인터페이스로 안전하게 수정할 수 있습니다.

## 세이브 기본 경로

윈도우 스팀판 기준 기본 저장 폴더 경로는 다음과 같습니다.

```text
%LOCALAPPDATA%\Wandering_Sword\Saved\<SteamID>\SaveGames
```

`<SteamID>` 위치에는 사용자의 스팀 고유 식별 번호 폴더가 생성됩니다.

## 3가지 실행 방식

사용 환경에 맞춰 세 가지 방식 중 원하는 형태를 선택해 실행할 수 있습니다.

1. **오프라인 단일 웹 문서 (`dist/WanderingSwordSaveEditor-v1.0.html`)**
   별도 설치나 외부 네트워크 연결 없이 최신 웹 브라우저에서 파일을 바로 열어 세이브를 편집하고 수정본 `.sav` 파일을 내려받습니다. 실제 세이브 파일이 없어도 내장된 체험용 데모 세이브로 모든 기능을 확인할 수 있습니다.
2. **윈도우 데스크톱 실행 파일 (`dist/WanderingSwordSaveEditor-v1.0.exe`)**
   WebView2가 내장된 윈도우 단일 실행 파일로, 실행 시 기본 세이브 경로를 자동 탐색하고 원본 `.bak` 자동 백업 후 즉시 덮어쓰기 및 사본 저장을 지원합니다.
3. **파이썬 표준 라이브러리 도구 (`wandering_sword_editor.py`)**
   외부 패키지 설치 없이 파이썬 3 표준 라이브러리만으로 명령줄 조회·검증·일괄 편집 및 로컬 루프백 보안 서버 구동을 지원합니다.

## 주요 편집 기능

### 빠른 프리셋 7종

| 식별자 | 대상 세이브 | 프리셋 이름 | 적용 내용 요약 |
| --- | --- | --- | --- |
| `wealth_max` | 일반 슬롯 | 최대 재화·수련치 | 보유 엽전 `9,999,999`, 주인공 무학 점수 `999,999` 이상, 경맥 점수 `99,999` 이상으로 설정 |
| `hero_cultivation` | 일반 슬롯 | 주인공 대성 수련 | 주인공의 기혈·진기·내공·공방·삼재 능력치와 추가 내공 상한을 대성 수치로 강화 |
| `party_favor_max` | 일반 슬롯 | 동료 호감도 100 | 현재 대열 동료와 주인공 사이의 양방향 호감도를 모두 `100`으로 설정 |
| `skills_lv10` | 일반 슬롯 | 습득 무공 10식 | 주인공과 현재 대열 동료의 습득 무공 등급을 모두 `10식`으로 상승 |
| `unlock_mounts_recipes` | 일반 슬롯 | 탈것·도안 전체 해금 | 탈것 10종(검독수리·판다·백호 등)과 연단·요리·단조 도안 전체 개방 |
| `reset_pill_limits` | 일반 슬롯 | 복용 제한 초기화 | 모든 인물의 영단·음식 복용 횟수 제한 기록 초기화 |
| `config_score_max` | 전역 설정 | 전승 점수·특전 해금 | `JHSaveConfig.sav`의 전승 점수를 `99,999`로 올리고 추천 전승 특전 일괄 해금 |

### 세부 편집 항목

- **개요 및 재화**: 저장 슬롯 요약 정보 확인, 보유 엽전, 전투 방식(실시간 전투 / 턴제 전투), 장착 탈것, 전역 전승 점수 및 전승 특전 편집
- **인물 능력치 69종**: 주인공(우문일) 및 동료의 핵심 전투·무기 수련·생활 기예·보조 배율 등 69종 능력치와 무학 점수·경맥 점수·추가 내공 상한 정밀 조정
- **무공, 경맥 및 복용 제한 초기화**: 습득 무공 추가·제거·등급(최대 10식) 조절, 경맥·혈도 전체 개통, 능력치 상승 물품 누적 복용 횟수 초기화
- **가방 물품 관리**: 검색·분류 필터, 수량 편집, 신규 물품 추가 및 미장착 물품 삭제 지원 (세이브 오염 방지를 위해 테스트용 디버그 물품은 원천 차단하며 기존 장비 고유 식별자·강화 부가 옵션은 그대로 유지)
- **동료 호감도 및 문파**: 동료 양방향 호감도(0~100), 문파 우호도 및 문파 공헌도 관리
- **탈것, 제작 도안 및 전승 특전**: 탈것 10종 해금, 연단·요리·단조 도안 일괄 해금, 다회차 전승 특전 개별·일괄 설정

## 주의 사항 및 안전 설계

- **경맥 돌파 동기화 안내**: 경맥·혈도를 일괄 개통하면 혈도 개방 상태와 경맥 점수가 즉시 반영됩니다. 경지 상승 연출이나 돌파 특전 갱신이 필요한 경우 게임 내 경맥 화면에서 혈도를 한 차례 재조정하면 정상적으로 동기화됩니다.
- **월드 데이터 무손실 보존**: 퀘스트 진행도(`Quests`), 채집 상태(`JHGatherSpecs`), 월드 배치 및 몬스터 인물 정보 등은 바이트 단위로 원본 그대로 무손실 보존합니다.
- **게임 실행 중 저장 차단**: 데이터 충돌을 막기 위해 일검풍운결 게임 프로세스(`JH-Win64-Shipping.exe` / `Wandering_Sword`)가 실행 중일 때는 파일 덮어쓰기를 자동으로 차단합니다.
- **자동 백업 및 무결성 검증**: 수정 파일 저장 전 원본 SHA-256 해시를 대조하고 `.bak` 백업 파일을 먼저 생성·검증한 뒤 원자적으로 교체합니다.
- **비정상 경로 및 특수 파일 차단**: 심볼릭 링크, 재분석 지점, 하드링크, 대체 데이터 스트림, 네트워크 공유 경로, 윈도우 예약 장치 이름을 통한 접근과 저장을 전면 차단합니다.
- **로컬 서버 보안 보호**: 내장 서버 구동 시 루프백 주소(`127.0.0.1`)에만 바인딩하며, 일회성 보안 토큰(`X-WS-Token`), 호스트·출처 헤더, 교차 사이트 요청 검사를 강제합니다.

## 명령줄 사용 예시

```bash
# 사용 가능한 빠른 프리셋 목록 확인
python3 wandering_sword_editor.py presets

# 세이브 파일 요약 정보 및 재화·인물 상태 한국어 조회
python3 wandering_sword_editor.py inspect 0.sav

# 세이브 파일 구조 및 내부 GVAS 무손실 왕복 직렬화 검증
python3 wandering_sword_editor.py validate 0.sav
python3 wandering_sword_editor.py validate JHSaveConfig.sav

# 프리셋 또는 개별 옵션을 적용하여 안전하게 편집 (원본 .bak 자동 백업 포함)
python3 wandering_sword_editor.py edit 0.sav --preset wealth_max --preset party_favor_max
python3 wandering_sword_editor.py edit JHSaveConfig.sav --preset config_score_max

# 로컬 루프백 전용 웹 편집기 서버 실행
python3 wandering_sword_editor.py serve "%LOCALAPPDATA%\Wandering_Sword\Saved\<SteamID>\SaveGames"
```

